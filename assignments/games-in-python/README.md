
# 📘 Assignment: Games in Python

## 🎯 Objective

Create a Hangman game where players guess letters to reveal a hidden word before running out of attempts. You'll practice using strings, loops, conditionals, and random selection.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description

Develop a working Hangman game using Python. The game should randomly select a word from a predefined list and allow players to guess letters one at a time. Display the current progress of guessed letters and track the number of incorrect guesses remaining. The game ends when the player either successfully guesses the word or runs out of attempts.

#### Requirements

Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses and show current progress in underscore format (_ _ _)
- Track incorrect guesses remaining and display them
- End when word is guessed or attempts exhausted
- Display clear win/lose messages with appropriate feedback
