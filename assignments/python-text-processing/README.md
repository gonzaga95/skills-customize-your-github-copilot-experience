# 📘 Assignment: Python Text Processing

## 🎯 Objective

Master string manipulation, file input/output operations, and text processing techniques in Python. You'll build practical tools to read, transform, and analyze text data from files.

## 📝 Tasks

### 🛠️ Build a Text Analysis Tool

#### Description

Create a Python program that reads a text file and performs various text processing operations. Your program should accept a filename as input, read the file contents, and provide analysis and transformations based on user choices. Implement functions to count words, find character frequency, convert case, remove duplicates, and search for patterns.

#### Requirements

Completed program should:

- Read text from a file and handle file not found errors gracefully
- Count total words, lines, and characters in the text
- Calculate character frequency and display the most common letters
- Convert text to uppercase, lowercase, and title case
- Remove duplicate lines and display unique content
- Search for and highlight specific words or patterns
- Write processed text to a new output file


### 🛠️ Create a Text File Formatter

#### Description

Build a text formatter that reads an input file and applies various formatting transformations. The tool should process raw text and output formatted versions with different styles and structures. This reinforces file I/O, string manipulation, and control flow concepts.

#### Requirements

Completed program should:

- Read lines from an input text file
- Remove extra whitespace and normalize line breaks
- Wrap text to a specified line width
- Apply indentation and formatting to text blocks
- Add line numbers to the output
- Write the formatted output to a new file
- Handle different text file encodings appropriately
